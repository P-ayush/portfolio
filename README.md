# Ayush Prasad Portfolio

A modern developer portfolio built with Next.js, TypeScript and Tailwind CSS.

## Features

- Responsive Design
- Animated UI
- Project Showcase
- Experience Timeline
- Skills Section
- Contact Section
- Resume Download

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
